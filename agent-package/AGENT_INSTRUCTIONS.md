# Agent Instructions

Use the seven numbered Markdown files as canonical post copy.

Allowed edits:
- LinkedIn line spacing
- tiny grammar fixes
- shortening background prose for platform length

Do not alter:
- CVE numbers
- PHP/application versions
- experiment counts
- proof boundaries
- attribution
- the public repository URL

If shortening a post, remove background prose before removing caveats.

When responding to comments, distinguish between:

1. official PHP advisory claims;
2. local laboratory reproduction;
3. conditional application findings;
4. scoped negative results.

Do not publish private PoCs, raw receipts, target details, worker-targeting logic, address calibration, exploit payloads, or unpublished research from the private repo.

Researchers requesting full scripts should be directed to the public repo's research-access process.
